production backend — 1000+ applications — hardened mid-event

Event Management Platform

A Django REST Framework backend for large-scale event and workshop management, deployed on octenium.com and built primarily to serve a React Native mobile scanner, a React web landing page, and a Python chatbot — all under real production load.

Django 5.2 + DRF 1000+ registrations React Native scanner JWT + OTP Cloudinary octenium.com · cPanel

mobile-first — attendance scannerReact Native · Expo

The backend was built primarily to serve a React Native + Expo mobile app used on-site for QR/barcode attendance scanning. JWT tokens live in expo-secure-store, the camera reads codes via expo-camera, and the UI is built with NativeWind. This is the surface that 1000+ registrations funneled through on the day.

backend output — what the API producesemail · certificates

Two artifacts that come straight off the backend. The registration email confirms the user's spot and attaches the entrance ticket. The PDF certificate is generated server-side via ReportLab with an embedded QR code and then stored on Cloudinary.

the security story — hardened mid-eventpost-attack

During the live event the platform came under attack. The response was not a patch — it was a multi-layer hardening pass that kept the system running without downtime while locking down every abuse vector.

throttlingMulti-level rate limiting

Registration, login, and email confirmation throttles across minute, hour, and day windows.

authJWT + OTP

simplejwt with refresh token rotation + django-otp for two-factor admin access.

validationInput validation

Email, phone, and data-type validation across all serializers.

captchareCAPTCHA

Google reCAPTCHA on form endpoints to block automated spam.

corsCORS lockdown

Only whitelisted origins; CSRF protection enforced.

storageCloudinary validation

File upload validation to reject unsafe file types.
