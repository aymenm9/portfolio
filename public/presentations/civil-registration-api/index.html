Civil Registration API

Django REST Framework · JWT · ReportLab · Cryptography · AI analysis

A focused civil registration backend for APCs, hospitals, and courts. The system manages sensitive records, controls access by institutional role, and turns approved records into official PDF documents.

What shipped

  • Birth, death, certificate, and burial permit workflows.
  • Role-based access control for three public institutions.
  • Automated PDF generation and an AI endpoint for death-data analysis.
  • A first working stage built by a three-person team under 12-hour competition pressure.
