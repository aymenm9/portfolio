# Civil Registration API

Hackathon-winning civil registration management API built with Django REST Framework.

- JWT authentication and role-based access for APCs, hospitals, and courts.
- Civil record management for births, deaths, certificates, and burial permits.
- Automated PDF document generation with ReportLab.
- Cryptography-backed security and an AI endpoint for death-data analysis.
- Built the backend in a team while two teammates developed the React frontend.
- First working stage delivered under a 12-hour competition time limit.
