# Aymen Identity — Reference (Light)

This is a personal taste reference, not a spec. Nothing here should be forced onto a design.
If a piece fits the current brief, use it. If it doesn't, skip it — that's the point of this being "light."

## Underlying philosophy

- Core belief: **"Less is more."** / **"Good design = simple design."**
- Preference for clean, minimal, uncluttered layouts over decoration for its own sake.
- Comfortable with a lot of negative space and a small number of confident elements rather than many small ones.

## Color — as a mood, not a palette to copy verbatim

The original palette leaned into a dark, moody, near-black base with one sharp accent:

- `#0d0d0d` — near-black base
- `#ffffff` — white, for contrast/text
- `#ac0000` — a deep, confident red accent (used sparingly, not as a wash)
- `#697355` — muted olive green (secondary/supporting tone)
- `#8c7265` — muted mauve/taupe (secondary/supporting tone)

Takeaway, not a rule: dark/near-black grounding + a single bold accent color, with 1-2 quiet neutral tones for supporting elements. The accent should feel deliberate and rare, not a gradient smeared everywhere.

## Typography

- **Montserrat** as a primary typeface across weights (Extra Bold for impact, Regular/Medium for body, Italic for occasional emphasis).
- Preference for geometric, clean sans-serifs generally — nothing overly decorative or script-heavy except for a personal signature/logotype flourish.

## Shape language

- Explicit design principle: **"the simplest shape in graphic design is the square and the circle."**
- Logomark built from an overlapping circle + square — geometric, minimal, mark-like rather than illustrative.
- Comfortable with sharp-edged geometric compositions (diagonal cuts, angled section dividers) as a structural device, used deliberately rather than everywhere.

## Layout habits

- Bold, large-scale headline text as a structural anchor on each section/slide.
- Short, confident supporting lines under headlines rather than long paragraphs.
- Comfortable mixing a photographic/personal element (a portrait, a signature) with otherwise flat graphic design — grounds the abstract mark in a real person.
- A consistent tagline device: **"Ready to bring your brand to the life"** used as a recurring anchor — the general pattern (a short recurring tagline used as a rhythm device across sections) is worth reusing even if the exact phrase isn't.
- A personal signature/wordmark treatment as a signoff — a small human touch against otherwise geometric/corporate elements.

## Tone

- Direct, uncluttered copy. Short declarative lines over marketing fluff.
- Confidence without being loud — the boldness is in typography weight and one accent color, not in noise.

## Explicit non-rules

- This is from an old personal graphic-design project (logo/branding, not code/web). Treat it as taste signal only — a portfolio built today doesn't need to inherit the exact red/black/olive palette, the exact circle+square mark, or Montserrat specifically.
- If the current brief's subject calls for something else entirely, that brief wins. This file is context, not constraint.
